# Vehicle Management System - SQL Database
This project provides a robust and scalable SQL Server-based Vehicle Management System  Database designed to streamline and optimize the operations of a vehicle rental or dealership company. The system efficiently manages entities such as vehicles, showrooms, inventory, staff, customers, rentals, services, payments, sales, insurance, and claims.
## Key Features
- Showroom and Inventory Management: Track vehicle availability across multiple showroom locations.
- Rental & Sales Tracking: Manage rental transactions and sales records with detailed pricing and vehicle info.
- Payment Processing: Support both installment and one-time payments, with full transaction audit logs.
- Vehicle Servicing: Record service types, charges, reviews, and completion status for maintenance workflows.
- Insurance & Claims: Track insurance policies, payments, and claim approvals for sold vehicles.
- User & Role Management: Secure role-based access for Admins, Managers, Technicians, and other staff.
- Audit Fields: All tables include created_at, updated_at, and is_deleted fields for record lifecycle tracking.
## Technologies Used
- SQL Server – as the relational database management system.
- T-SQL – for table creation, constraints, and data manipulation.
## Purpose
To automate and centralize vehicle management, reducing redundancy and manual effort while enabling efficient tracking of vehicles, customers, drivers, and financial transactions.
